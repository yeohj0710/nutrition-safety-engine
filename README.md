# 여형준 연구

고위험 임상상황의 영양보충제 근거지도. 최종 수집 자료는 문헌-질문 조합 **263,982행**이며 유지 판정은 **78,136행**이다. R20260905 사후 검토 7,843행을 반영해 기존 판정 581행을 정정하고, 수집 오류로 복원한 6,922행을 처음 선별했다.

## 최종 자료

- `research/final/manifest.json`: 입력·산출물·코드의 해시와 최종 결과.
- `../evidence-recollect/data/yeo/final/`: 정정한 문헌 자료, 사후 기준, 검토 기록, 최종 판정과 집계.
- `research/systematic_review/`: 현재 사이트 자료.

최종 핵심 문헌은 주제 적합성·결과 요약·한국어 번역을 직접 검토했다. 전체 후보는 AI 선별과 검색어 필터 결과이며 모두 개별 검토한 목록은 아니다.

철회된 논문과 철회 공지는 수집 기록에 보존한다. 공개 화면에는 철회 상태와 서지정보만 표시하며 결과 인용과 AI 요약에는 사용하지 않는다.

## 환자 상황과 문헌 설명

상담 설명은 `gpt-5.6-luna`, 추론 수준 `max`로 작성한다. 입력한 상황과 선택 문헌의 전체 초록·검토한 결과 문장을 함께 읽고, 대상·성분·사용량·기간·결과와 적용 범위의 차이를 설명한다. 문단별 출처와 수치·단위를 검사하며, 생성 실패 시에도 문헌의 결과 문장을 표시한다. 문헌 검색과 연구 판정은 기존 규칙을 유지한다.

서버용 원자료는 `research/consult/*.json.gz`다. 현재 문헌 자료가 바뀌면 `npm run build:consult`로 다시 만든다. 이 명령은 저장된 초록을 묶으며 문헌을 재수집하거나 모델을 호출하지 않는다. 배포에는 압축 원자료가 포함된다. AI 설명은 비동기로 추가되며 최대 4분을 기다린다.

`/api/consult/compose`는 검토 문헌을 앞세워 8편까지, 초록은 문장 경계에서 3,200자까지만 모델에 보낸다(`src/lib/consult-compose.ts`). 응답은 NDJSON으로 흘려보내며 먼저 서버 원자료로 만든 문헌별 정리(interim)를 주고, 8초마다 심장박동으로 연결을 유지한 뒤 결과를 보낸다. 같은 요청은 한 모델 호출에 묶고, 사용자가 조회를 바꾸거나 화면을 떠나 요청이 끊기면 모델 호출도 끊는다. 모델이 못 쓰거나 심판에 걸리면 같은 문헌별 정리를 돌려준다.

## 재현 검사

```powershell
npm run validate:research
npm run validate:evidence
npm run typecheck
npm run lint
npm test
npm run build
```

검사는 저장된 자료를 대조하고 결과를 다시 계산한다. 모델이나 유료 API를 호출하지 않는다. 문헌을 새로 읽는 대량 작업은 gpt-5.6-luna를 사용한다.

## 과거 평가와 보존 기록

정정 전 AI 비교는 253,810행의 표본 추출틀에서 3,250행을 채점한 결과이며 일치도는 74.79%다. 원래 판정·표본·채점·잠금 파일을 바꾸지 않았다. 사후 정정 지표와 과거 맹검 지표를 섞지 않는다. 두 AI의 기준 적용 차이도 있어 이 값을 최종 자료의 정확도나 임상적 정확도로 읽지 않는다.

과거 버전 폴더는 감사와 빌드 의존성을 위한 보존 경로다. 현재 자료를 고르는 기준은 이 안내와 최종 명세다. 공개 주소는 https://nutrition-safety-engine.vercel.app 이며 배포 기록은 별도로 확인한다.
