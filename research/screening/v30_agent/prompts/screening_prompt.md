# v3.0 에이전트 직접 선별 판정 기준 (P2)

이 문서는 v3.0 트랙의 제목·초록 선별 판정 기준을 고정한다. 실행 중 이 문서를 수정하지 않는다.
판정 주체는 에이전트 자신이며, 별도의 언어모델이나 외부 API를 호출하지 않는다.

## 1. 이 작업의 성격

탐색적 문헌지도(exploratory literature map)를 만드는 분류다. 체계적 문헌고찰의 최종 선별이
아니다. 어떤 문헌도 최종 제외로 판정하지 않는다. 사람의 include/exclude 판정이 아니며
`retain` / `deprioritize` / `uncertain` 세 라벨만 사용한다.

주어진 연구질문에 대해 이 기록을 지도에 남길 가치가 있는지만 판단한다. 임상 권고, 복용
지시, 용량 판단, 사람이 검증했다는 주장을 만들지 않는다. 초록에 없는 사실을 만들지 않는다.

## 2. 판정 라벨

| 라벨 | 정의 |
| --- | --- |
| `retain` | 해당 질문의 대상집단 또는 고위험 상황, 영양·허브 보충제 노출, 안전성 결과 또는 임상적으로 의미 있는 상호작용이 함께 다뤄질 가능성이 있다. 지도에 유지한다. |
| `deprioritize` | 주제가 질문과 뚜렷이 다르다. 보충제 노출을 다루지 않거나, 안전성 신호 없이 효능만 다루거나, 동물 전용·시험관 전용이거나, 연구가 아닌 논평·사설·소식란이다. 우선순위를 낮춘다. |
| `uncertain` | 주어진 제목·초록만으로는 이 기록이 질문에 대응하는지 확정할 수 없다. |

세 라벨의 경계에서 판단이 서지 않으면 `uncertain`을 쓰고 이유를 남긴다. 파싱 실패나
fallback 이라는 개념은 존재하지 않는다. 모든 행에 판정이 있다.

## 3. 판정 절차

각 행마다 다음 네 가지를 차례로 확인한다.

1. **P — 대상집단/상황**: 기록이 질문이 지정한 대상집단 또는 임상상황을 다루는가.
   사람 대상인가. 동물 전용 또는 시험관 전용이면 `animal_term_present`를 남기고
   `deprioritize` 한다.
2. **I — 노출**: 식이보충제, 비타민, 무기질, 허브·식물성 제제, 기능성 성분 노출을 다루는가.
   처방의약품 단독 연구, 식품 섭취 패턴 연구, 보충제가 아닌 중재는 노출로 보지 않는다.
   단, 항응고 질문(HRS5)에서 약물–보충제 상호작용을 다루면 노출로 본다.
3. **O — 결과**: 안전성 결과(이상반응, 독성, 출혈, 전해질 이상, 간손상, 기형, 상호작용,
   검사치 이상, 입원, 사망 등)를 다루는가. 효능·유효성만 다루고 안전성 신호가 전혀 없으면
   `deprioritize` 한다. 다만 안전성 결과를 부수적으로라도 보고하면 `retain` 대상이 된다.
4. **S — 연구설계**: 무작위시험, 코호트, 환자–대조군, 단면연구, 등록자료·약물감시 연구,
   증례보고·증례군, 체계적 고찰이면 설계 신호가 있다. 서술적 종설(narrative review)과
   임상지침도 안전성 정보를 정리하면 지도에 유지할 수 있다. 사설, 편집자에게 보내는 편지,
   학회 소식, 논문 정정문은 `deprioritize` 한다.

세 축(P, I, O) 중 둘 이상이 명확히 충족되고 나머지 하나가 부정되지 않으면 `retain` 한다.
셋 중 하나라도 명확히 부정되면 `deprioritize` 한다. 확인할 정보 자체가 없으면 `uncertain`.

## 4. reason_codes

다음 값만 사용한다. 여러 개를 함께 쓸 수 있다.

| 코드 | 의미 |
| --- | --- |
| `population` | 질문의 대상집단·임상상황이 확인된다 |
| `exposure` | 보충제·허브 노출이 확인된다 |
| `outcome` | 안전성 결과 또는 상호작용이 확인된다 |
| `human_signal` | 사람 대상 자료임이 확인된다 |
| `design_signal` | 판단 가능한 연구설계가 확인된다 |
| `animal_term_present` | 동물 전용 또는 시험관 전용 연구다 |
| `off_topic` | 질문과 주제가 뚜렷이 다르다 |
| `insufficient_abstract` | 초록이 없거나 판단에 필요한 정보가 부족하다 |

## 5. confidence

`high` / `medium` / `low` 중 하나.

- `high`: 제목·초록에서 P, I, O가 모두 명시적으로 확인되거나, 주제가 명백히 다르다.
- `medium`: 두 축이 명시적이고 나머지 한 축은 문맥으로 추정된다.
- `low`: 한 축만 확인되거나 초록이 없다.

## 6. 초록이 없는 행

`abstract` 가 빈 문자열인 행은 제목만으로 판정한다. 이 행은 반드시 다음을 따른다.

- `evidence_basis` = `title_only`
- `confidence` 상한 = `low`
- `reason_codes` 에 `insufficient_abstract` 를 반드시 포함

초록이 있는 행은 `evidence_basis` = `abstract` 이다.

## 7. 출력 스키마

행마다 JSON 한 줄을 쓴다.

```json
{"record_id":"pubmed:NNNNNNNN","question_id":"HRS1_PERIOPERATIVE","decision":"retain","reason_codes":["population","exposure","outcome"],"confidence":"high","evidence_basis":"abstract","status":"ok"}
```

`status` 는 항상 `ok` 다. 판정하지 못한 행을 남기지 않는다.

## 8. 연구질문 (v3.0 PICOS, 고정)

출처 `research/searches_v3/ai_picos/picos_definition.json`

### HRS1_PERIOPERATIVE
수술 또는 침습적 시술을 받는 성인에서 수술 전 식이·허브 보충제 노출은 비노출 또는 통상
관리와 비교해 출혈, 수혈, 마취 상호작용 또는 수술주위 합병증과 관련되는가?

- P 수술 또는 침습적 시술을 받는 성인
- I 수술 전 식이보충제 또는 허브 보충제 노출
- C 비노출, 중단, 또는 통상 수술주위 관리
- O 출혈, 수혈, 마취 상호작용, 수술주위 합병증
- S 무작위시험, 코호트, 환자–대조군, 단면연구, 증례군, 체계적 고찰

### HRS2_KIDNEY_DISEASE
만성콩팥병 또는 투석 환자에서 비처방 비타민·무기질·허브 보충제 노출은 비노출 또는 통상
관리와 비교해 전해질 이상, 신독성 또는 심혈관 이상반응과 관련되는가?

- P 만성콩팥병 또는 투석 환자
- I 비처방 비타민, 무기질 또는 허브 보충제 노출
- C 비노출, 위약 또는 통상 관리
- O 고칼륨혈증, 고칼슘혈증, 신독성, 심혈관 이상반응
- S 무작위시험, 코호트, 환자–대조군, 약물감시 연구, 증례군, 체계적 고찰

### HRS3_PREGNANCY
임신 중 식이·허브 보충제 노출은 비노출 또는 통상 산전관리와 비교해 산모 독성, 임신 합병증,
태아 이상 또는 신생아 이상반응과 관련되는가?

- P 임신부와 태아 또는 신생아
- I 임신 중 식이보충제 또는 허브 보충제 노출
- C 비노출, 위약 또는 통상 산전관리
- O 산모 독성, 임신 합병증, 선천성 이상, 태아·신생아 이상반응
- S 무작위시험, 임신 코호트, 환자–대조군, 등록자료 연구, 증례군, 체계적 고찰

### HRS4_LIVER_DISEASE
기존 간질환이 있는 환자에서 식이·허브 보충제 노출은 비노출 또는 통상 관리와 비교해 간손상,
간기능 악화 또는 입원과 관련되는가?

- P 기존 간질환이 있는 성인 또는 소아 환자
- I 식이보충제 또는 허브 보충제 노출
- C 비노출 또는 통상 관리
- O 약인성 간손상, 간기능 악화, 간부전, 입원
- S 코호트, 환자–대조군, 약물감시 연구, 증례군, 체계적 고찰

HRS4 에서는 기존 간질환자 코호트가 아니어도, 보충제로 인한 간손상 자체를 다루면 P 를
충족한 것으로 본다. 간손상 발생이 곧 간질환 상태이기 때문이다.

### HRS5_ANTICOAGULATION
항응고제를 사용하는 환자에서 식이·허브 보충제 병용은 비병용과 비교해 출혈, 혈전, 응고검사
변화 또는 약물 상호작용과 관련되는가?

- P 비타민 K 길항제, 직접경구항응고제 또는 헤파린을 사용하는 환자
- I 식이보충제 또는 허브 보충제 병용
- C 보충제 비병용 또는 기준 기간
- O 주요·경미 출혈, 혈전색전증, 응고검사 변화, 약물 상호작용
- S 무작위시험, 코호트, 환자–대조군, 자기대조 연구, 증례군, 체계적 고찰

HRS5 에서 항혈소판제만 다루고 항응고제를 전혀 다루지 않으면 P 를 충족하지 않는다.
다만 출혈 위험 관점에서 항응고·항혈소판을 함께 다루면 충족으로 본다.
