# 폐기 격리 — 소형 로컬 모델 실행 시도

이 폴더의 파일은 v3.0 트랙에서 중단된 실행 시도의 산출물이다. 문헌 선별과 참조표준 채점을 소형 로컬 언어모델로 수행했으나 판정 품질이 연구 요건에 미달했고, 참조표준 대비 지표의 신뢰구간이 6배 범위로 벌어져 어떤 결론도 지지하지 못했다. 따라서 전량 폐기한다. 이 폴더의 어떤 파일도 v3.0 체인의 입력, 정답, 근거, 비교 대상으로 사용하지 않으며, 논문·발표 원고·최종 보고서·매니페스트 어디에도 이 실행을 언급하지 않는다. 히스토리 보존을 위해 삭제하지 않고 이동만 했다.

## 보존 대상이 아닌 것

`data/curated_v3/evidence_map.csv`, `data/curated_v3/corpus_manifest.json`,
`research/searches_v3/` 는 P1 검색 산출물이며 이 실행과 무관하다. 그대로 유효하고 v3.0 본 트랙이 계속 사용한다.
