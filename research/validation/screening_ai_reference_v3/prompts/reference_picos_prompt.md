# v3.0 P3 참조표준 축별 채점 프롬프트 (동결)

이 프롬프트는 P2 선별 프롬프트와 **다른 과업**을 정의한다.
P2 는 "이 레코드가 주제에 맞는가"를 통째로 물었다.
여기서는 그렇게 묻지 않는다. 레코드마다 **P·I·C·O·S 다섯 축을 따로 채점**하고,
종합 라벨은 사람이 아니라 **코드가 아래 규칙으로 도출**한다.
축 판정 단계에서 retain/deprioritize 같은 종합 판단을 떠올리지 말고,
각 축이 해당 질문의 정의를 충족하는지만 본다.

입력에는 제목·초록·질문 ID 만 있다. P2 라벨, confidence, reason_codes, batch_id 는
블라인드 파일에 존재하지 않는다.

## 축 정의와 허용값

`population` / `intervention` / `comparator` / `outcome` : `yes` | `no` | `unclear`

- `yes` — 제목·초록에 해당 축을 충족한다는 명시적 근거가 있다.
- `no` — 해당 축과 명백히 어긋나는 근거가 있다(예: 대상이 다른 질환군, 노출이 보충제가 아닌 처방약).
- `unclear` — 어긋난다는 근거도, 충족한다는 근거도 없다. 초록이 없어 판단할 수 없는 경우를 포함한다.

`design` : 다음 중 하나

- `human_clinical` — 사람 대상 임상시험·코호트·환자대조군·단면연구·증례보고/증례군·약물감시 보고
- `human_secondary` — 사람 근거를 종합한 체계적 고찰·메타분석·임상지침·등록자료 분석·서술적 고찰
- `animal` — 동물 실험 전용
- `in_vitro` — 세포·조직·시험관·in silico 전용
- `unclear` — 설계를 특정할 수 없음

## 축 판정 규칙

1. C(비교군)는 **기록만 한다.** 단일군 증례·감시보고도 안전성 근거지도에서는 정당한 근거이므로
   C 부재를 배제 사유로 쓰지 않는다.
2. 초록이 없으면 제목만으로 판단한다. 제목에서 확인되지 않는 축은 전부 `unclear` 로 둔다.
   초록 없이 `yes` 를 주려면 제목 자체가 해당 축을 명시해야 한다.
3. 사람 대상 근거와 동물·시험관 근거가 함께 있으면, 결론의 근거가 어느 쪽인지로 정한다.
   사람 데이터가 부수적 언급에 그치면 `animal` 또는 `in_vitro` 로 본다.
4. 노출이 처방약이고 보충제는 배경 문장에만 등장하면 `intervention` 은 `no` 다.

## 종합 라벨 도출 규칙 (코드가 수행, 사람이 손대지 않음)

```
if design in ("animal", "in_vitro"):
    label = reference_deprioritize
elif "no" in (population, intervention, outcome):
    label = reference_deprioritize
elif population == intervention == outcome == "yes":
    label = reference_retain
else:
    label = reference_uncertain
```

## 출력 형식

레코드마다 JSON 한 줄. 종합 라벨 필드는 쓰지 않는다(코드가 채운다).

```json
{"blind_id":"B0001","population":"yes","intervention":"yes","comparator":"no","outcome":"yes","design":"human_clinical"}
```

## 질문별 PICOS 정의

### HRS1_PERIOPERATIVE

수술 또는 침습적 시술을 받는 성인에서 수술 전 식이·허브 보충제 노출은 비노출 또는 통상 관리와 비교해 출혈, 수혈, 마취 상호작용 또는 수술주위 합병증과 관련되는가?

- **P**: 수술 또는 침습적 시술을 받는 성인
- **I**: 수술 전 식이보충제 또는 허브 보충제 노출
- **C**: 비노출, 중단, 또는 통상 수술주위 관리
- **O**: 출혈, 수혈, 마취 상호작용, 수술주위 합병증
- **S**: 무작위시험, 코호트, 환자-대조군, 단면연구, 증례군, 체계적 고찰

### HRS2_KIDNEY_DISEASE

만성콩팥병 또는 투석 환자에서 비처방 비타민·무기질·허브 보충제 노출은 비노출 또는 통상 관리와 비교해 전해질 이상, 신독성 또는 심혈관 이상반응과 관련되는가?

- **P**: 만성콩팥병 또는 투석 환자
- **I**: 비처방 비타민, 무기질 또는 허브 보충제 노출
- **C**: 비노출, 위약 또는 통상 관리
- **O**: 고칼륨혈증, 고칼슘혈증, 신독성, 심혈관 이상반응
- **S**: 무작위시험, 코호트, 환자-대조군, 약물감시 연구, 증례군, 체계적 고찰

### HRS3_PREGNANCY

임신 중 식이·허브 보충제 노출은 비노출 또는 통상 산전관리와 비교해 산모 독성, 임신 합병증, 태아 이상 또는 신생아 이상반응과 관련되는가?

- **P**: 임신부와 태아 또는 신생아
- **I**: 임신 중 식이보충제 또는 허브 보충제 노출
- **C**: 비노출, 위약 또는 통상 산전관리
- **O**: 산모 독성, 임신 합병증, 선천성 이상, 태아·신생아 이상반응
- **S**: 무작위시험, 임신 코호트, 환자-대조군, 등록자료 연구, 증례군, 체계적 고찰

### HRS4_LIVER_DISEASE

기존 간질환이 있는 환자에서 식이·허브 보충제 노출은 비노출 또는 통상 관리와 비교해 간손상, 간기능 악화 또는 입원과 관련되는가?

- **P**: 기존 간질환이 있는 성인 또는 소아 환자
- **I**: 식이보충제 또는 허브 보충제 노출
- **C**: 비노출 또는 통상 관리
- **O**: 약인성 간손상, 간기능 악화, 간부전, 입원
- **S**: 코호트, 환자-대조군, 약물감시 연구, 증례군, 체계적 고찰

### HRS5_ANTICOAGULATION

항응고제를 사용하는 환자에서 식이·허브 보충제 병용은 비병용과 비교해 출혈, 혈전, 응고검사 변화 또는 약물 상호작용과 관련되는가?

- **P**: 비타민 K 길항제, 직접경구항응고제 또는 헤파린을 사용하는 환자
- **I**: 식이보충제 또는 허브 보충제 병용
- **C**: 보충제 비병용 또는 기준 기간
- **O**: 주요·경미 출혈, 혈전색전증, 응고검사 변화, 약물 상호작용
- **S**: 무작위시험, 코호트, 환자-대조군, 자기대조 연구, 증례군, 체계적 고찰
