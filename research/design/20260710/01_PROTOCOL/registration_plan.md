# 프로토콜 공개·등록 계획

## 우선순위

1. 지도교수 검토 후 날짜가 남는 공개 저장소에 프로토콜과 검색식 버전을 보관한다.
2. 해당 연구 유형이 허용되면 OSF Registries 또는 적절한 리뷰 등록 플랫폼을 검토한다.
3. 등록이 불가능하거나 시점상 소급 등록이 되면 이를 명확히 밝힌다.

## 공개할 항목

- 연구 질문과 포함 기준
- 검색원과 검색식 초안
- 선별과 추출 절차
- AI 평가 설계
- 합성·검증 지표
- 프로토콜 변경 규칙

## 공개하지 않을 항목

- 저작권 제한 원문 PDF
- API 키와 개인정보
- 평가 전에 정답이 노출되면 안 되는 비공개 시나리오 세트

## 버전 규칙

- `protocol-v1.0`: 최종 검색 전 승인본
- `protocol-v1.1`: 검색식 기술 수정
- `protocol-v2.0`: 연구 질문 또는 주요 분석 변경

각 버전은 Git tag, 날짜, SHA-256을 기록한다.
