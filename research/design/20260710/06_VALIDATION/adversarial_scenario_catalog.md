# 경계·공격 시나리오 카탈로그

- `EPA`가 저자 이름·기관 약어에만 나타나는 문헌 또는 입력
- `vitamin K`가 음식 섭취로만 존재하고 보충제가 아닌 상황
- warfarin이 과거 약물이고 현재 중단된 상황
- DOAC인데 VKA용 INR 메시지가 잘못 나오는 상황
- calcium 1,200 mg가 제품 총량인지 elemental calcium인지 불명확
- vitamin D의 IU와 microgram 변환 경계
- vitamin C가 multivitamin 안의 소량인지 단독 고용량인지
- 신결석 종류가 uric acid stone인데 calcium oxalate 규칙이 적용되는 상황
- hypercalcemia와 hypercalciuria의 혼동
- 성분명 철자 오류, 한글·영문 혼합, 상품명
- 복합제에서 동일 성분 중복 합산
- 음수·0·비현실적 용량
- 연령·성별 누락
- 임신, 소아, 투석 등 연구 범위 밖 population
- 여러 항응고제 또는 항혈소판제 동시 입력
- 출혈 증상이 있는 긴급 상황과 단순 예방 상담의 구분
