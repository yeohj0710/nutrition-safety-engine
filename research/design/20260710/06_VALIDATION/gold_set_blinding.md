# 정답 시나리오 독립성과 블라인딩

## 역할 분리

- 규칙 구현자: 엔진 코드와 데이터 계약 담당
- gold author 1·2: 임상상황과 예상 행동 작성
- adjudicator: 불일치 해결
- evaluator: 동결된 gold와 엔진 출력 비교

한 사람이 여러 역할을 맡을 수밖에 없으면 역할 충돌을 기록하고, 최소한 정답 작성 시 엔진 출력은 가린다.

## 잠금 절차

1. 시나리오 입력과 정답 초안 작성
2. 독립 판단 비교
3. 합의와 근거 링크
4. `gold_status=locked`
5. 파일 해시와 날짜 기록
6. 그 뒤에만 엔진 실행

## 변경

잠금 후 정답을 바꾸면 변경 전 값을 보존하고 다음을 기록한다.

- 엔진 오류 때문인지
- 정답 정의 오류 때문인지
- 근거 업데이트 때문인지
- 스키마가 모호했는지

엔진 결과에 맞추기 위한 사후 정답 변경은 금지한다.
