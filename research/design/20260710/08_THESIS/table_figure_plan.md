# 표와 그림 계획

## 그림

1. 전체 연구 설계: 근거검토 → AI 평가 → claim/rule → 검증
2. PRISMA 흐름도
3. report-study 연결 예시 또는 데이터 계보
4. 질문별 비뚤림 위험 시각화
5. 가능한 질문의 forest plot
6. AI 선별 confusion matrix 또는 recall-workload 곡선
7. AI 추출 필드별 성능
8. 근거→claim→rule→scenario 추적 그림
9. 엔진 검증 오류 분포

## 본문 표

1. 다섯 연구 질문과 중요 결과
2. 데이터베이스와 검색일
3. 포함 연구 특성
4. 질문별 효과 요약
5. GRADE Summary of Findings
6. AI 선별 성능
7. AI 추출 성능과 오류
8. validated claim/rule 현황
9. 시나리오 검증 성능
10. 전문가 검토 결과

## 부록 표

- 전체 검색식
- 원문 제외 목록
- 세부 추출표
- 비뚤림 위험 근거
- AI 프롬프트·설정·반복 실행
- 전체 규칙 목록
- 전체 시나리오 결과
- 프로토콜 변경 이력

## 생성 원칙

- 숫자는 수동 입력하지 않는다.
- 표·그림마다 생성 스크립트와 입력 파일을 기록한다.
- 그림의 n과 본문의 n이 다르면 CI가 실패하도록 검사한다.
- 복잡한 표는 부록으로 보내고 본문에는 해석에 필요한 열만 둔다.
