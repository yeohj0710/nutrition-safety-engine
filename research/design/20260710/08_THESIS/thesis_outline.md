# 졸업논문 상세 구성

논문은 데이터 고정 후 작성한다. 아래는 내용 구조이며 결과 숫자를 미리 채우지 않는다.

## 표지와 초록

- 국문 제목
- 영문 제목
- 국문초록: 배경 2~3문장, 목적 1문장, 방법 4~6문장, 실제 결과 수치, 결론, 핵심어
- 영문초록: 국문을 기계적으로 직역하지 않고 같은 사실을 정확히 표현

초록은 마지막에 작성한다.

## 1. 서론

### 1.1 임상 문제

항응고제 복용과 칼슘옥살산 신결석 위험에서 보충제 안전성 판단이 왜 조건 의존적인지 구체적 예로 설명한다.

### 1.2 근거의 분산과 상담의 어려움

1차 연구, 기존 검토, 공공기관 자료의 역할 차이를 설명한다. 검색 hit가 많다는 사실을 문제의 크기로 쓰지 않는다.

### 1.3 기존 디지털 도구와 AI 활용의 한계

출처 추적, 범위, 재현성, 자동 추출 오류를 설명한다. 일반적인 “AI가 발전했다” 서론을 길게 쓰지 않는다.

### 1.4 연구 필요성

근거검토, AI 성능평가, 결정적 규칙 검증이 왜 함께 필요한지 논리적으로 연결한다.

### 1.5 목적과 연구 질문

세 목적과 A1~B3 질문을 명확히 제시한다.

## 2. 연구대상 및 방법

### 2.1 전체 연구 설계

세 연구 구성요소와 시간 순서를 그림으로 제시한다.

### 2.2 프로토콜과 변경

서명 계획서와 실제 프로토콜의 차이가 있으면 투명하게 설명한다. 등록·공개 위치와 변경 이력을 제시한다.

### 2.3 체계적 근거검토

- 질문과 포함 기준
- 정보원과 검색일
- 검색식 개발·동료검토
- 중복 제거
- 제목·초록 및 원문 선별
- 연구·보고서 연결
- 추출
- 비뚤림 위험
- 합성
- GRADE

### 2.4 AI 보조 절차 평가

- 모델과 버전
- 입력과 출력 스키마
- 개발·평가 자료 분리
- 사람 정답
- 반복 실행
- 지표와 오류 분석

### 2.5 근거 주장과 규칙 설계

- claim 정의
- 규칙 상태와 action class
- 원문 추적
- 검증 전 규칙 비노출

### 2.6 시스템 구현

- 데이터 흐름
- 결정적 엔진
- 앱 구조
- 개인정보와 런타임 AI 비사용

### 2.7 시나리오와 전문가 검증

- 시나리오 구성과 독립성
- gold set 잠금
- 지표와 목표
- 전문가 검토
- 조건부 사용성

### 2.8 통계분석

질문별 합성, AI 지표, 엔진 지표, 신뢰구간, 소프트웨어 버전.

## 3. 결과

### 3.1 검색과 선별

- 데이터베이스별 결과
- 중복 제거
- 제목·초록 결정
- 원문 제외 사유
- 최종 study/report 수
- PRISMA

검색 hit가 아니라 최종 포함 연구의 특성이 중심이다.

### 3.2 포함 연구 특성

질문별로 설계, population, 노출, 결과, 추적기간을 제시한다.

### 3.3 비뚤림 위험

도구별 도메인 판단과 주요 문제를 설명한다.

### 3.4 질문별 근거합성

A1, A2, B1, B2, B3 순서. 각 절에서:

1. 연구 수와 설계
2. 주요 효과
3. 이질성과 통합 여부
4. 근거확실성
5. 적용 한계

### 3.5 AI 선별 성능

민감도, 정밀도, F2, 반복성, 오류 유형, 사람 검토 절감 가능성을 제시한다.

### 3.6 AI 추출 성능

필드별 성능과 숫자·단위·원문 위치 오류를 제시한다. 평균 하나로 숨기지 않는다.

### 3.7 근거 주장과 규칙

질문별 validated claim과 rule 수, 상태, 행동 분포, traceability 결과.

### 3.8 엔진 검증

시나리오 분포, 주요 지표, CI, critical/major 오류, 수정 전후 결과.

### 3.9 전문가·사용성 결과

실제로 수행한 경우에만 쓴다. 미수행 계획을 결과에 넣지 않는다.

## 4. 고찰

### 4.1 주요 결과

각 연구 구성요소의 가장 중요한 결과를 수치와 함께 요약한다.

### 4.2 임상 근거 해석

다섯 질문에서 근거가 일치하거나 상충하는 이유를 population, 용량, 제형, 결과 정의로 설명한다.

### 4.3 AI 보조의 실제 가치와 한계

어떤 필드는 잘했고 어떤 필드는 위험했는지, 사람 검토가 어느 지점에서 필수였는지 논의한다.

### 4.4 규칙 도구의 의미

성능과 오류를 근거로 어느 수준까지 사용할 수 있는지 한정한다. 임상 유효성이나 환자 결과 개선을 검증하지 않았다면 그렇게 쓰지 않는다.

### 4.5 기존 연구와 비교

기존 systematic review와 디지털 도구 연구의 결과·방법 차이를 구체적으로 비교한다.

### 4.6 강점

사전 프로토콜, 원문 추적, 사람 정답, 독립 시나리오, 결정적 실행 등 실제 수행한 강점만 쓴다.

### 4.7 한계

검색원 접근, 언어, 소규모 근거, 간접성, 사람 검토자 수, 모델 변화, 시나리오 기반 검증, 외부 타당성을 설명한다.

### 4.8 후속 연구

새 성분 확대보다 외부 검증, 실제 상담 환경, 업데이트 체계를 우선한다.

## 5. 결론

한 페이지 안에서 목적에 직접 답한다. 앱을 만들었다는 사실보다 근거의 범위, AI의 성능, 도구의 검증 수준을 제시한다.
