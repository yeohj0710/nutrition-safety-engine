# 장별 승인 체크리스트

## 서론

- [ ] 연구 질문으로 직접 이어지는 임상 문제인가
- [ ] 앱이나 AI를 과장하는 일반론이 아닌가
- [ ] 기존 연구의 실제 공백을 인용으로 설명했는가
- [ ] 세 목적이 결과 장 구조와 대응하는가

## 방법

- [ ] 다른 연구자가 검색과 선별을 재현할 수 있는가
- [ ] 사람과 AI의 역할이 분리되어 있는가
- [ ] 모든 지표가 사전 정의되었는가
- [ ] 프로토콜 변경이 기록되었는가
- [ ] IRB/기관 판단을 사실대로 썼는가

## 결과

- [ ] 방법에 없는 분석이 없는가
- [ ] 최종 study 수와 report 수를 구분했는가
- [ ] 모든 숫자에 분모가 있는가
- [ ] 효과크기와 불확실성을 보고했는가
- [ ] 실패와 오류도 보고했는가
- [ ] 계획이나 향후 작업을 결과로 쓰지 않았는가

## 고찰

- [ ] 결과를 반복하지 않고 이유와 의미를 설명하는가
- [ ] 상충 근거를 숨기지 않는가
- [ ] 일반화 범위를 지키는가
- [ ] AI 성능의 작업별 차이를 논의하는가
- [ ] 도구 검증과 임상 유효성을 구분하는가

## 결론

- [ ] 세 목적에 직접 답하는가
- [ ] 수치와 근거확실성이 반영되었는가
- [ ] 새로운 주장을 추가하지 않는가
- [ ] 한계를 무시한 홍보 문구가 없는가

## 전체

- [ ] 국문·영문 초록의 수치가 같은가
- [ ] 본문·표·그림·부록·앱의 버전이 같은가
- [ ] 참고문헌이 실제 인용과 일치하는가
- [ ] 메타 작업 문구가 남아 있지 않은가
- [ ] 반복 문단이나 분량 채우기 부록이 없는가
