# 기존 산출물 재감사 요약

재감사 실행일: 2026-07-10  
실행 도구: `tools/audit_existing_artifacts.py`  
대상: 첨부 ZIP에서 추출한 `여형준` 폴더 전체

## 재현 결과

- 파일: 461개
- CSV: 105개(중복 보관본 포함)
- 설정된 고위험 패턴 적발: 120건

| 유형 | 적발 수 | 해석 |
|---|---:|---|
| 검색 결과 상위 관련도 제한 | 20 | `sort=relevance`, 상위 100건 저장 등이 여러 최신·보관본에 반복됨 |
| 검색 내보내기 cap | 30 | 20건 또는 100건만 가져온 실행이 전체 검색처럼 재사용될 위험 |
| 원문 확인 전 규칙 | 30 | `seed_requires_human_source_check`가 규칙·검증 자료에 남아 있음 |
| 완료 선언 문구 | 31 | 실질적인 원문검토·질평가보다 문서/배포 완료를 앞세운 기록이 다수 존재 |
| 연도 파싱 실패 | 5 | 236건의 발행연도가 전부 결측으로 집계된 복제 파일 존재 |
| 연구유형 충돌 흔적 | 4 | “종설논문 아님”, “차라리 SR” 피드백과 기존 지침이 동시에 남아 있음 |

적발 수는 독립적인 오류 건수가 아니라, 동일 산출물의 복제본을 포함한 **패턴 출현 횟수**다. 그러나 핵심 최신 CSV에서도 상위 N 제한, 원문 확인 전 규칙, 연도 전부 결측이 확인되므로 단순한 오래된 백업 문제로 축소할 수 없다.

## 문체 스모크 테스트

기존 논문 텍스트 22,701자를 자동 검사한 결과:

- 동일 문장 5회 반복 사례 2종
- 전형적인 이분법 문장 패턴 경고 1건
- 내부 작업 메타 표현 0건

자동 문체 검사는 제한된 정규식 기반 스모크 테스트다. 문장 자연스러움이나 논증의 깊이를 판정하는 완전한 평가가 아니며, 실제 감사에서 더 중요한 문제는 반복 문장보다 **방법이 완료되지 않았는데 결과 문서가 먼저 완성된 구조**다.

## 결론

기존 파일은 다음 용도로만 사용한다.

1. 알려진 문헌이 새 검색에서 회수되는지 확인하는 seed
2. 실패한 검색·분류·규칙 설계의 회귀 사례
3. 새 앱 마이그레이션 시 기능 비교 자료
4. 연구계획 변경의 역사 기록

새 근거자료로 승격하려면 새 프로토콜에 따라 다시 검색되고, 원문 선별·추출·비뚤림 위험 평가·사람 검증을 통과해야 한다.
