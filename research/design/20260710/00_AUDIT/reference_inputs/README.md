# 역사적 입력 자료

이 폴더는 재설계의 출발점을 재현하기 위한 **읽기 전용 역사 자료**다. 여기 있는 연구계획서, 기존 졸업논문, 이전 작업 지침과 피드백을 새 연구 결과로 간주하거나 그대로 덮어써서는 안 된다.

## 포함 자료

- `연구계획서_여형준_260618_서명본.pdf`: 행정적으로 제출된 방향성과 범위를 확인하는 기준 자료
- `졸업논문_여형준_260618.pdf`: 기존 작성본의 구조·표현·방법론 결함을 비교하기 위한 자료
- `260406_피드백.txt`, `260413 피드백.txt`: 지도 피드백
- `기존_AGENTS.md`, `기존_정리_기준.txt`: 이전 GPT 작업 규칙과 정리 기준
- 텍스트 추출본 2개: 검색·문체 감사 편의를 위한 비권위적 파생물. 인용이나 판정은 원본 PDF를 우선한다.

## 사용 규칙

1. 원본은 수정하지 않는다.
2. 새 프로토콜과 충돌하면 변경 기록을 남기고 새 프로토콜을 따른다.
3. 기존 숫자·규칙·문장은 검증 전 `legacy_unverified`다.
4. 논문 인용이나 근거 판정은 원문과 정식 서지자료를 다시 확인한다.
