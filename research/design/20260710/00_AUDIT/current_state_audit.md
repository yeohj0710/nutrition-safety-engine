# 현 상태 감사 보고서

감사 기준일: 2026-07-10

## 1. 확인한 자료

- 첨부 ZIP: 461개 파일, 약 57.4 MB
- 핵심 서명 연구계획서: 10쪽
- 기존 졸업논문: 20쪽
- 근거 CSV: 22개
- 교수 피드백 메모 2개
- 기존 작업 지침 `AGENTS.md`
- 공개 배포와 최신 생산 배포 메타데이터

공개 배포는 HTTP 200으로 확인되었으며, 확인 시점의 생산 커밋은 `33658e3a9ee8dbf6d21ac94a5aa49202b5bf22e5`였다. 로컬 ZIP의 문서와 데이터는 주로 2026년 6월 4일~18일 상태이므로, 현재 저장소와 동일하다고 가정할 수 없다. 소스 코드 수준 감사는 Codex가 저장소를 직접 연 뒤 Gate 0에서 다시 수행해야 한다.

## 2. 총평

기존 작업에는 검색식, 후보문헌, 일부 핵심 근거, 규칙 엔진, 배포 가능한 웹앱이 있다. 따라서 완전히 버릴 필요는 없다. 그러나 현재 산출물은 다음 이유로 학위논문의 최종 연구 결과로 사용할 수 없다.

- 검색이 전체 검색결과가 아니라 관련도 정렬 상위 일부를 저장했다.
- 제목·초록 자동분류가 원문 포함 판단처럼 사용되었다.
- 원문 검토와 제외 사유 기록이 완료되지 않았다.
- 개별 연구와 여러 보고서를 구분하지 않았다.
- 비뚤림 위험과 근거확실성 평가가 표준 절차로 수행되지 않았다.
- 규칙 후보의 원문 검증과 독립 시나리오 검증이 충분하지 않다.
- 검색량, 후보 수, 규칙 수가 문서와 앱에서 일관되지 않다.
- 기존 논문은 완료되지 않은 후속 작업을 스스로 인정하면서도 결과와 결론을 먼저 작성했다.

## 3. 치명적 문제

| ID | 심각도 | 관찰 | 왜 문제인가 | 필수 조치 |
|---|---|---|---|---|

| C02 | 치명적 | `retrieved_pmids=100;sort=relevance`, `max_records=100` 기록 | 상위 N 제한을 숨기고 검색 hit를 전체 근거 규모처럼 표시 | 기존 검색은 파일명부터 `pilot_truncated`로 격리 |

| C04 | 치명적 | 원문 검토가 향후 작업이라고 논문에 반복 기재 | 최종 포함 연구, 효과 추정, 질평가가 존재하지 않음 | 결과 장을 폐기하고 원문 선별 완료 후 재작성 |
| C05 | 치명적 | 논문 유형이 종설로 표기되지만 교수 피드백은 “종설논문 아님” | 연구 정체성과 평가 기준이 충돌 | 프로토콜을 체계적 근거검토+개발·검증 연구로 확정 |
| C06 | 치명적 | 규칙 seed가 `seed_requires_human_source_check` | 검증 전 규칙이 사용자 결과에 영향을 줄 수 있음 | 검증 상태가 `validated`인 규칙만 thesis mode에 노출 |
| C07 | 치명적 | 앱에 연구계획서 밖 성분·상황이 함께 노출 | 연구 질문, 데이터, 결과, UI의 범위가 불일치 | 핵심 범위와 탐색 기능을 구조적으로 분리 |

## 4. 주요 문제

### 4.1 검색원 숫자의 의미 혼재

- PubMed 12,023건, 최신 합계 8,957건, 누적 저장 236건이 서로 다른 실행을 가리킨다.
- Europe PMC 4,793건과 Crossref 247,709건을 합친 252,502건이 “보조검색 hit”로 표시된다.
- Crossref 결과는 임상 근거 검색 규모와 직접 비교할 수 없다.
- ClinicalTrials.gov는 전체 건수만 조회하고 각 검색에서 한 건만 저장했다.

새 연구에서는 `search_run_id`별 수치만 사용하고, 데이터베이스 간 hit를 품질 지표로 합산하지 않는다.

### 4.2 문헌특성 계산 오류

`문헌특성분포 260604.csv`는 236건 모두 출판연도 누락으로 기록했다. 다른 파일에 연도 정보가 존재하므로 파싱 또는 조인 실패로 보인다. 이 파일에서 계산한 분포는 사용하지 않는다.

### 4.3 자동분류 거짓 양성

후보문헌에는 보충제 노출 연구가 아닌 출혈 위험점수 연구도 포함되었다. `EPA` 같은 짧은 문자열이나 안전성 단어가 문맥 없이 일치한 것으로 보인다. 단순 문자열 일치 결과를 임상적 관련성으로 간주하면 안 된다.

### 4.4 근거 추출의 제한

핵심근거추출표는 10행뿐이며, 공공기관 fact sheet와 1차 연구, 체계적 문헌고찰이 한 표에서 동일한 방식으로 “최종 포함” 처리되었다. 연구설계별 역할, 연구 중복, 원문 위치, 비뚤림 위험, 질문별 근거 묶음이 없다.

### 4.5 검증 설계 부족

기존 시나리오는 5건이다. 기대 결과를 엔진 개발 과정에서 만든 것으로 보이며 독립된 정답 작성 절차가 없다. 규칙 110개 또는 화면 범위 37개에 대한 민감도·정밀도·오류 분석을 할 수 없다.

### 4.6 논문 품질

- 국문과 영문 초록의 언어가 완전히 분리되지 않았다.
- 실제 연구 결과보다 검색 절차와 향후 계획을 반복 설명한다.
- 본문 약 9쪽 이후 유사 문장과 부록이 반복된다.
- 수치가 많지만 분모, 연구 단계, 독립 연구 수가 명확하지 않다.
- “체계적”, “근거 기반”, “개인맞춤” 같은 표현이 실증보다 앞선다.

## 8. 감사 결론

이 프로젝트의 가장 큰 위험은 “많은 파일과 숫자가 이미 있으므로 연구도 거의 끝났다”는 착시다. 실제로는 연구의 핵심인 전체 검색, 사람 원문판정, 연구 단위 자료, 질평가, 분석, 독립 검증이 남아 있다. 새 작업은 기존 문서를 보완하는 순서가 아니라, 프로토콜과 데이터 사슬을 다시 만든 뒤 마지막에 문서를 쓰는 순서로 진행해야 한다.
