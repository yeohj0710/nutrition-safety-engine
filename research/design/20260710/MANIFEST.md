# 패키지 Manifest

생성일: 2026-07-10

이 패키지는 연구 재설계를 위한 실행 규격과 템플릿을 포함한다. 개별 파일 해시는 최종 `manifest.json`에 기록한다.

## 구성

- 00_AUDIT: 현재 상태와 기존 데이터 처리
- 01_PROTOCOL: 연구 질문, 포함 기준, 프로토콜
- 02_RETRIEVAL: 검색 실행과 기록
- 03_SCREENING: 사람 선별과 AI 우선순위 평가
- 04_EXTRACTION: 원문 자료추출과 AI 추출 평가
- 05_SYNTHESIS: 근거합성, 근거 주장, 규칙 변환
- 06_VALIDATION: 시나리오, 전문가, 사용성 검증
- 07_REPO: 저장소 구조, 계약, 테스트, 마이그레이션
- 08_THESIS: 논문 구성과 문체
- 09_CODEX: 실행 에이전트 지침
- 10_QA: 완료 기준과 최종 점검
- tools: 감사·검증 보조 스크립트
