# 중복 제거와 연구 단위 연결 프로토콜

## 1. 식별자 계층

1. PMID, DOI, trial registration과 같은 고유 식별자 정확 일치
2. 정규화 제목 + 첫 저자 + 연도 정확 일치
3. 제목 유사도 + 저자·표본·기관·기간 유사성 후보
4. 사람이 원문 또는 초록을 보고 최종 판정

## 2. 정규화

- DOI는 `https://doi.org/`, `doi:` 접두어를 제거하고 소문자로 변환한다.
- PMID는 숫자만 유지한다.
- 제목은 Unicode 정규화, 소문자화, 구두점·중복 공백 제거본을 별도 필드로 둔다.
- 원래 값은 절대 덮어쓰지 않는다.

## 3. 삭제 금지

중복 레코드를 물리적으로 삭제하지 않는다. 각 `record_id`를 보존하고 `duplicate_cluster_id`, `canonical_record_id`, `duplicate_reason`, `verified_by`를 기록한다.

## 4. record, report, study

- `record`: 데이터베이스에서 검색된 하나의 서지 레코드
- `report`: 논문, 초록, 등록자료, 보조분석 등 하나의 보고물
- `study`: 같은 참가자 집단과 연구 프로토콜에 기반한 연구

같은 RCT의 원 논문과 출혈 보조분석은 서로 다른 `report_id`이지만 같은 `study_id`일 수 있다. 메타분석의 독립 단위는 `study_id`다.

## 5. 연결 증거

연결 판단에 사용한 정보를 기록한다.

- trial acronym/registration
- 모집기관과 기간
- 표본크기와 군 크기
- 중재·비교군
- 저자와 연구자
- baseline 특성

## 6. 품질검사

- 자동 중복 클러스터의 무작위 10% 이상 수동 감사
- 포함 연구와 관련된 모든 클러스터 전수 감사
- 한 study가 둘 이상의 독립 연구로 잘못 분리되지 않았는지 확인
- 여러 연구가 한 study로 잘못 합쳐지지 않았는지 확인
