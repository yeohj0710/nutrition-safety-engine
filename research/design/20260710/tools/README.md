# 도구

- `audit_existing_artifacts.py`: 기존 폴더의 파일·CSV와 위험 패턴 감사
- `validate_research_bundle.py`: 설계 패키지 자체의 구조·JSON·CSV 검사
- `validate_provenance.py`: source→claim→rule 참조 무결성 검사
- `check_thesis_style.py`: TXT/MD/DOCX의 메타 문구, 반복 문장, AI투 표현 검사
- `generate_manifest.py`: 폴더 전체 SHA-256 manifest 생성

모든 도구는 Python 표준 라이브러리만 사용한다.
