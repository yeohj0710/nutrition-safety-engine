# 전체 완료 승인 기준

아래 필수 항목이 하나라도 미통과면 프로젝트를 “완료”라고 표시하지 않는다. 외부 차단으로 미통과한 항목은 정확히 표시한다.

## A. 연구 정체성과 프로토콜

- [ ] 최종 제목과 목적이 실제 방법·결과와 일치
- [ ] 연구 질문 A1~B3 또는 승인된 축소 범위가 명확
- [ ] protocol v1.0이 최종 검색 전에 고정
- [ ] 모든 주요 변경이 amendment log에 있음
- [ ] 서명 계획서와 실제 연구의 차이를 설명
- [ ] 등록·공개 상태를 사실대로 보고

## B. 검색

- [ ] 질문별 전체 검색식 전문 존재
- [ ] 데이터베이스와 플랫폼, 검색일 존재
- [ ] 검색원 접근 제한과 대안 기록
- [ ] 상위 N 관련도 제한 없음
- [ ] total hits와 exported records 설명 가능
- [ ] raw 파일과 해시 존재
- [ ] 검색식 동료검토 기록 존재
- [ ] 제출 전 필요한 업데이트 검색 완료

## C. 선별

- [ ] record/report/study 구분
- [ ] 중복 제거 audit 통과
- [ ] 사람 제목·초록 결정 완료
- [ ] 원문 전수 독립 또는 계획된 이중검토 완료
- [ ] 원문 제외 문헌과 주된 이유 존재
- [ ] reviewer agreement와 불일치 보고
- [ ] AI 단독 제외 0건
- [ ] PRISMA 수치가 결정 테이블에서 자동 생성

## D. 추출과 질평가

- [ ] 핵심 필드와 숫자 이중 확인
- [ ] 원문 인용과 locator 존재
- [ ] 연구·보고서 중복 해소
- [ ] 설계에 맞는 RoB 도구와 버전 기록
- [ ] 독립 평가와 합의 기록
- [ ] 공식 자료와 1차 연구의 근거층 분리

## E. 합성

- [ ] 질문·노출·결과·연구설계별 분리
- [ ] 메타분석 여부의 사전 기준과 결정 기록
- [ ] 부적절한 효과크기 통합 없음
- [ ] 비정량 합성도 구조화됨
- [ ] 중요 결과별 GRADE 또는 명시된 대안
- [ ] 효과크기, CI, 이질성, 한계 보고
- [ ] 선택적 결과 보고 없음

## F. AI 평가

- [ ] 사람 gold가 먼저 잠김
- [ ] 개발 세트와 평가 세트 분리
- [ ] 모델·버전/접근일·설정·프롬프트 해시 존재
- [ ] 원시 출력 보존
- [ ] 선별 recall과 critical FN 보고
- [ ] 추출 필드별 성능 보고
- [ ] unsupported claim, locator, 단위 오류 보고
- [ ] 반복 실행 안정성 보고
- [ ] 효율과 오류를 함께 해석

## G. Claim과 규칙

- [ ] validated claim마다 source/report/locator 존재
- [ ] 규칙마다 하나 이상의 validated claim 존재
- [ ] 임계값 출처와 단위 존재
- [ ] 적용 범위·예외·누락정보 존재
- [ ] 심각도와 근거확실성 분리
- [ ] thesis scope 밖 규칙이 주요 결과에 없음
- [ ] legacy rule 자동 승격 0건

## H. 엔진과 앱

- [ ] 런타임 LLM 호출 없음
- [ ] 입력 스키마와 단위 변환 테스트
- [ ] partial-string false positive 회귀 테스트
- [ ] API contract 테스트
- [ ] provenance 무결성 100%
- [ ] 동일 입력 결정성 100%
- [ ] 건강정보 로그 없음
- [ ] UI와 API 결과 일치
- [ ] 연구 감사 화면과 사용자 화면 분리
- [ ] commit, bundle, deployment 일치

## I. 시나리오·전문가 검증

- [ ] gold 시나리오가 구현과 독립적으로 작성
- [ ] 목표 분포 또는 변경 이유 기록
- [ ] sensitivity, precision, exact match, CI 보고
- [ ] critical false negatives 상세 보고
- [ ] 오류 수정 후 회귀 검사
- [ ] 전문가 수와 자격, 실제 절차 보고
- [ ] 사용성은 기관 판단 후에만 수행
- [ ] 실제 환자 결과를 검증했다고 과장하지 않음

## J. 논문

- [ ] 학과 최신 양식 준수
- [ ] 방법과 결과 절이 대응
- [ ] 검색 hit가 중심 결과가 아님
- [ ] 모든 수치에 분모와 단계 존재
- [ ] 결과와 해석 분리
- [ ] 실패·불확실성·상충 근거 포함
- [ ] 반복·분량 채우기 문단 없음
- [ ] 과도한 AI투 명사열과 홍보 표현 없음
- [ ] formal document meta terms 0
- [ ] 국문·영문 초록 수치 일치
- [ ] 참고문헌 실재·인용 일치
- [ ] DOCX와 PDF 시각검사 통과

## K. 재현성과 제출

- [ ] Git tag와 clean status
- [ ] final manifest와 SHA-256
- [ ] raw/curated/generated 구분
- [ ] 분석 코드로 표·그림 재생성 가능
- [ ] 공개할 수 없는 원문이 repo에 없음
- [ ] README에 재현 절차
- [ ] 모든 blocker와 미수행 항목 공개
- [ ] 제출 폴더에 필요한 문서·부록·데이터 목록 완료
