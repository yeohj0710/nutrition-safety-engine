# 즉시 중단하고 수정해야 할 신호

## 연구

- 검색 hit가 늘어났다는 이유로 연구가 깊어졌다고 설명
- `sort=relevance`, `max_records=100` 결과를 PRISMA에 사용
- 제목·초록 후보를 “포함 논문”이라고 부름
- 원문 검토를 향후 과제로 두고 결론 작성
- 여러 보고물을 독립 연구처럼 중복 계산
- 체계적 문헌고찰과 그 안의 1차 연구를 같은 효과합성에 중복 포함
- GRADE 대신 임의의 level 1/2/3 사용
- 유의하지 않은 결과를 안전하다고 해석

## AI

- 모델 출력만으로 gold 생성
- LLM-as-judge 점수를 정확성으로 보고
- 모델·프롬프트 버전 없음
- 자연스러운 요약을 사실 정확성으로 간주
- low-confidence record 자동 제외
- 원문에 없는 숫자·인용

## 규칙·코드

- claim 없이 규칙 존재
- `seed_requires_human_source_check`가 사용자에게 노출
- 문자열 일부가 우연히 일치해 규칙 발동
- 연구 범위 밖 성분이 thesis 지표에 포함
- 화면 숫자가 하드코딩
- 테스트 수 통과만 강조하고 임상 FN을 평가하지 않음
- 같은 입력 결과가 달라짐

## 논문

- “혁신적, 고도화, 개인맞춤, 근거 기반”을 수치 없이 반복
- 같은 경고 문장을 여러 절에서 반복
- 부록으로 분량만 채움
- 방법에 없는 결과 또는 결과 없는 방법
- 영문초록에 한국어 잔존
- 실제 하지 않은 전문가 검증·사용성·IRB를 쓴 흔적
- placeholder, TODO, Codex, prompt 같은 작업 문구
