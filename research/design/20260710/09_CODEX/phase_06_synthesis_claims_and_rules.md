# Phase 6. 근거합성, claim, 규칙 작성

## 목적

질문별 근거를 적절히 합성하고, 검증된 근거 주장과 제한된 규칙으로 변환한다.

## Entry

- 추출과 RoB 자료 잠금
- 분석 계획 확정

## 작업

1. 질문별 임상·방법 이질성 평가
2. 메타분석 가능 여부 기록
3. 가능한 분석과 민감도 분석
4. 불가능한 경우 구조화 서술합성
5. outcome별 GRADE
6. claim 초안 작성
7. claim 원문·적용 범위 이중 확인
8. rule 초안과 action class
9. 임계값·예외·누락정보 검증
10. scope 상태 지정
11. legacy rule과 차이 분석

## 산출물

- analysis datasets and scripts
- question-specific evidence tables
- forest plots if justified
- GRADE tables
- validated claim registry
- source-verified rule registry
- analysis and rule decision logs

## Exit

- 부적절한 pooling 없음
- 모든 주요 결과에 합성·확실성 설명
- validated claim 100% locator 존재
- thesis rule 100% in-scope claim 참조
- legacy 자동 승격 0건
