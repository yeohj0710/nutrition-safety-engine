# Phase 8. 학위논문 작성과 최종 일치 검사

## 목적

고정된 연구 결과를 사람이 읽기 쉬운 학위논문으로 작성하고, 데이터·코드·앱·문서의 수치를 일치시킨다.

## Entry

- data/analysis/rule/scenario freeze
- release tag와 manifest
- 학과 최신 형식 확인

## 작업

1. 방법 사실 기록
2. 표·그림 자동 생성
3. 결과 장 작성
4. 고찰 작성
5. 서론과 연구목적 조정
6. 결론
7. 국문·영문 초록
8. 참고문헌 검증
9. 스타일·중복·메타 문구 검사
10. 수치와 ID consistency check
11. DOCX 생성과 양식 확인
12. PDF 변환과 페이지별 시각검사
13. 지도교수 수정 반영과 amendment/decision 기록
14. 최종 manifest와 제출 폴더

## 산출물

- final thesis DOCX/PDF
- final tables/figures
- supplement/appendices
- final consistency report
- submission manifest
- reproducibility README

## Exit

- 결과 없는 계획 문장 없음
- 모든 숫자의 데이터 원천 확인
- 국문·영문·표·앱 수치 일치
- 반복·분량 채우기 문단 없음
- formal document meta terms 0
- PDF 표 잘림·빈 페이지·폰트 문제 없음
- 모든 제한점과 미수행 항목 정직하게 보고
