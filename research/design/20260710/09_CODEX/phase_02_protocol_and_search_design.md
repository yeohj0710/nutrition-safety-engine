# Phase 2. 프로토콜 확정과 검색 설계

## 목적

연구 질문, 포함 기준, 결과, 검색원, AI 평가, 검증 기준을 검색 전에 고정한다.

## Entry

- Phase 1 통과
- 지도교수에게 제출 가능한 설계 요약 준비

## 작업

1. 서명 계획서·교수 피드백·학과 지침 대조
2. 다섯 질문 workload 예측
3. 범위 유지/축소 결정과 amendment
4. 결과 정의와 중요도 확정
5. 데이터베이스·원문 접근 matrix
6. 질문별 검색식 초안과 sentinel set
7. PRESS 검토 큐
8. 선별·추출·RoB·GRADE 도구 확정
9. AI 개발/평가 분할과 지표 확정
10. 시나리오 검증·전문가 검토 계획 확정
11. 기관 윤리 판단 필요 여부 확인
12. protocol v1.0과 등록/공개

## 산출물

- `research/protocol/protocol-v1.0.md`
- `research/protocol/amendments.csv`
- `research/protocol/access_matrix.csv`
- `research/protocol/outcome_priority.csv`
- `research/searches/search_strategy_drafts/`
- `research/review_queue/PRESS_review.*`
- protocol 공개 URL 또는 소급/미등록 사유

## Exit

- 질문별 PICO와 포함 기준이 모순 없음
- 검색원 접근상태와 대안 기록
- 최종 검색 전 승인 또는 명확한 pending 승인 상태
- AI와 사람 역할·지표 고정
- 결과를 본 뒤 변경할 항목이 남지 않음
