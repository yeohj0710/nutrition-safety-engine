# 부분 이중 선별 표본계획

전수 이중 선별이 불가능한 경우에만 사용한다.

## 1. 전수 이중 검토 대상

- 1차 검토자의 `include`
- 1차 검토자의 `uncertain`
- AI와 사람이 크게 불일치한 기록
- 기존 파일럿 핵심근거와 sentinel study
- 모든 원문

## 2. 제외 표본

1차 제외를 다음 층으로 나눈다.

- question_id
- database
- publication year band
- exclusion reason
- AI priority band

각 층에서 무작위 표본을 뽑아 전체 제외의 최소 20%를 독립 재검토한다. 작은 층은 전수 검토한다.

## 3. 확대 규칙

표본에서 포함 또는 uncertain으로 바뀐 기록이 발견되면:

1. 원인을 분류한다.
2. 같은 오류 조건에 해당하는 전체 기록을 재검토한다.
3. 해당 층의 추가 20%를 검토한다.
4. 새 오류가 없을 때까지 반복한다.

## 4. 보고

표본 추출 난수 seed, 코드, 층별 분모·표본 수, 변경된 결정 수를 공개한다.
