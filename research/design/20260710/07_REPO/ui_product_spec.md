# 사용자 화면 제품 사양

## 사용자

주 사용자는 약사 또는 근거를 확인할 수 있는 상담자다. 일반 사용자에게 직접 제공할 경우 표현과 안전장치를 별도로 검증한다.

## 입력

- 복용 약물과 종류
- 보충제 성분, 제형, 용량, 단위, 빈도
- 주요 병력
- 관련 검사값
- 출혈 또는 급성 증상
- 입력 불확실성

상품명만 입력하면 성분·함량 확인을 요청하고 임의 추정하지 않는다.

## 결과

### 1. 우선 행동

고정된 action class와 짧은 문장.

### 2. 확인된 조건

엔진이 어떤 입력을 사용했는지 보여준다.

### 3. 추가 질문

결정에 필요한 누락정보를 명시한다.

### 4. 근거

- 질문 ID
- 근거 요약
- 확실성
- 적용 범위
- 출처

### 5. 한계

도구가 진단, 처방, 개인별 최종 결정을 제공하지 않는다는 점을 명시한다.

## 연구 감사 화면

- PRISMA 흐름
- 포함 연구와 evidence table
- AI 평가 성능
- 규칙 검증 결과
- bundle/commit/version

사용자 화면의 “관련 후보문헌”은 제거한다. 검증 전 후보가 사용자에게 근거처럼 보일 수 있기 때문이다.
