# AI 보조 원문 정보추출 프로토콜

## 1. 목적

대규모 언어모델이 원문에서 사전 지정 필드를 얼마나 정확하게 찾고, 그 값을 검증 가능한 원문 위치와 함께 제시하는지 평가한다. 자연스러운 요약문 생성이 주목적이 아니다.

## 2. 전제

- 사람이 합의한 추출 자료가 정답이다.
- 프롬프트 개발 문헌과 최종 평가 문헌을 분리한다.
- 모델 출력은 별도 `ai_candidate` 테이블에 저장한다.
- AI 값이 사람 자료를 자동 덮어쓰지 않는다.

## 3. 원문 준비

1. 합법적으로 접근한 PDF/HTML을 사용한다.
2. 원본 파일 해시를 기록한다.
3. 텍스트 레이어가 있으면 직접 추출한다.
4. 스캔 PDF는 필요한 페이지만 최소한으로 OCR하고, OCR 사용 사실과 품질을 표시한다.
5. 표가 핵심이면 페이지 이미지와 표 구조를 사람이 확인한다.
6. 참고문헌, 머리말, 반복 footer가 본문으로 섞이지 않도록 정리한다.

## 4. 문맥 제공

한 번에 전체 논문을 무비판적으로 넣지 않는다. 다음 단위로 나눈다.

- abstract
- methods population/intervention
- outcomes definition
- results text
- relevant tables/figures
- safety/adverse event section

문서 조각마다 원문 페이지와 heading을 보존한다. 모델이 다른 문서의 내용을 섞지 못하도록 report_id를 명시한다.

## 5. 추출 단계

### 단계 A: 보고 여부

각 필드에 `extracted`, `not_reported`, `unclear`, `not_applicable`를 선택한다.

### 단계 B: 값과 단위

원문 값을 그대로 기록하고, 정규화 값은 별도 필드에 둔다.

### 단계 C: 근거 위치

짧은 원문 인용, 페이지, 절, 표·그림을 제시한다. 근거 위치가 없으면 extracted로 인정하지 않는다.

### 단계 D: 내부 검증

- 사건 수와 분모가 효과크기와 모순되지 않는지
- 군 이름이 뒤바뀌지 않았는지
- adjusted와 unadjusted가 섞이지 않았는지
- 시간점이 맞는지
- 전체 집단과 하위군이 섞이지 않았는지

## 6. 평가 표본

- 최종 포함 보고물 최소 30편 또는 전수
- 질문·연구설계·표 복잡성·결과 유형을 층화
- 프롬프트 개발 표본은 평가에서 제외
- 최소 20편에서 3회 반복 실행해 안정성 평가

포함 보고물이 30편보다 적으면 전수를 사용하고 정확한 분모와 신뢰구간을 보고한다.

## 7. 지표

### 명시 사실 필드

- exact match accuracy
- precision, recall, F1
- numeric value accuracy
- unit accuracy
- locator accuracy
- quote entailment accuracy

### 해석 필드

- 사람 합의와의 일치
- 오류 유형
- 과도한 일반화 비율

### 안전성 지표

- unsupported claim rate
- wrong-arm rate
- wrong-timepoint rate
- study/report mixing rate
- critical numeric error count

### 효율

- 사람 단독 추출 시간
- AI 후보 검토·수정 시간
- 순시간 절감
- 수정된 필드 비율

시간은 같은 사람이 가능한 한 동일한 조건에서 측정한다. 효율만 높고 오류가 증가하면 성공으로 판단하지 않는다.

## 8. 반복성과 버전

- 모델명과 버전 또는 접근일
- API/앱 방식
- 프롬프트 전문과 해시
- 모델 설정
- 입력 조각과 해시
- 원시 출력과 해시
- 파싱·재시도 횟수

모델 서비스가 바뀌면 동일 모델로 간주하지 않는다.

## 9. 사람 검증

검증자는 AI 출력과 사람 정답을 비교하되, 가능하면 처음에는 정답 값을 가린 채 원문부터 판정한다. 불일치는 다음으로 분류한다.

- AI 오류
- 사람 추출 오류
- 스키마 정의 문제
- 원문 자체 불명확
- 복수 정답 가능

사람 정답도 수정될 수 있으며, 수정 이력을 보존한다.

## 10. 결과 해석

일부 필드에서 높은 정확도가 나와도 모든 필드에 일반화하지 않는다. 특히 연구설계, 인과적 해석, 결과 정의, 표의 복합 하위군은 별도 보고한다. 학위논문에서는 “AI가 검토를 자동화했다”보다 “어떤 작업에서 어느 정도의 정확도와 수정 부담을 보였다”고 쓴다.
