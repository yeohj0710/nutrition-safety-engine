# 학위논문 작성 상태

상태: `blocked_before_results_freeze`

현재는 최종 학위논문 DOCX/PDF를 생성하지 않는다. 사람 선별·원문 검토·추출·RoB·합성·독립 시나리오 검증이 완료되지 않았기 때문이다. 빈 결과를 정상 결과처럼 쓰거나 synthetic proxy 수치를 연구 결과로 옮기지 않는다.

작성 가능한 사실은 프로토콜, 감사 방법, 데이터 격리 방식, 검색·선별·검증 계획뿐이다. 결과 장, 고찰, 결론, 국문·영문 초록의 결과 수치는 data/analysis/rule/scenario freeze 뒤 생성한다.

DOCX/PDF 생성 시 학과 최신 양식을 먼저 확인하고, 문서 렌더링 후 모든 페이지 PNG를 100%로 검사한다. 현재 DOCX/PDF 부재는 누락을 숨긴 것이 아니라 금지 규칙을 지킨 상태다.
