# 사람·AI 역할과 동결 지표

## v2.1 실제 역할 (2026-07-25 개정, AM-006)

프로토콜 v2.0 §5·§9와 지도교수 피드백(2026-07-20, AM-005)에 따라 **사람 선별을 수행하지 않는다.**
분류·추출은 전 과정을 자동으로 수행하고, 사람은 검색어 설계와 결과 공개만 맡는다.

| 단계 | 사람 | 자동 | 동결 지표 |
|---|---|---|---|
| 검색식 설계 | 작성·확정 | 없음 | 검색식 원문, 실행 로그, 원본 XML 해시 |
| 중복 후보 | 없음 | DOI·정규화 제목 일치 | 후보 수, 결정 로그 |
| 제목·초록 분류 | 없음 | 규칙 기반 이중 프로파일 + LLM 탐색 분류 | 두 방식의 일치·불일치, 교차표, Cohen κ, 스키마 유효성, 재현성 |
| PICOS 추출 | 없음 | 정규식 문장 추출 + LLM 게이트 | locator 완전성, 용량 추출 수, 게이트 통과·탈락 수 |
| claim/rule | 없음 | 자동 구조화 | locator completeness, clinical_actions 공란 유지 |
| 시나리오 검증 | 없음 | 합성 fixture | 결정성, 라우팅 정확도, 계보 완전성, 임상행동 누출률, legacy 누출률 |

## 보고하지 않는 지표

사람 gold standard 가 없으므로 **민감도·특이도·정밀도·재현율·F1·F2·정확도·critical false
negative 를 산출하지 않는다** (v2.0 §9). 자동 방식 사이의 일치도만 보고한다.
어떤 자동 판정도 체계적 문헌고찰의 최종 포함·제외로 표시하지 않는다.

## 원칙

동일 설정으로 최소 3회 실행해 결정성을 확인한다. 모든 수치는 생성 코드와 입력 해시에서
재생성하며 하드코딩하지 않는다. LLM 층은 모델·추론강도·프롬프트 해시를 매니페스트에 남긴다.

## 보류 자료

`research/validation/screening_gold/` 에 층화 무작위 표본 420건(시드 20260727)이 동결돼 있다.
현재 어떤 산출물도 이 표본을 참조하지 않는다. 나중에 사람 판정을 도입하기로 하면 그때
채점해 정확도 지표를 낼 수 있도록 남겨 둔 것이며, 그 시점에는 별도 개정이 필요하다.

해당 설계는 `protocol-v1.0.md` 와 `research/screening/` 의 v1 큐에 그대로 보존한다.
